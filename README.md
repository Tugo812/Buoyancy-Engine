# Buoyancy-Engine
- Designed and built a ~$400 prototype (commercial floats start around $20,000) meant to sink and rise by pulling water in and out with two servo-driven pistons
  
- Programmed an Arduino to read and calibrate a pressure sensor, calculate depth and switch between sink and ascent modes. Chose an Arduino over an ESP32 because the sensor’s 4.5 V output is above the ESP32’s 3.3 V input limit
  
- Designed flanges in Autodesk Fusion (resin 3D-printed), laser-cut acrylic pistons, soldered the sensor wiring and built a 6 V → 5 V power supply with a buck converter
